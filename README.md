# Theory of The Question of Existence (TQE)

**A Computational Framework for Investigating the Emergence of Physical Laws from Energy-Information Coupling**

**Author**: Stefan Len

## Overview

The Theory of The Question of Existence (TQE) is a theoretical framework proposing that stable physical laws emerge from the primitive coupling of Energy (E) and Information (I). Rather than being axiomatic, physical constants and laws are hypothesized to dynamically stabilize through a probabilistic selection mechanism during cosmogenesis.

This repository contains computational implementations, simulation pipelines, and research documentation exploring this hypothesis through Monte Carlo simulations of universe ensembles.

## Core Hypothesis

TQE posits that:
- Physical laws are not pre-existing but emerge from quantum fluctuations in a pre-law state
- Stability arises from the coupling of vacuum energy fluctuations with an information-theoretic orientation parameter
- This coupling creates a "Goldilocks window" where law-governed universes can stabilize
- The framework yields falsifiable predictions about statistical anomalies in cosmological observations

## Quick Start

For detailed installation and usage instructions, navigate to the specific version directory and consult its README:

```bash
cd TQE_Simulation_v1.0.0
```

General requirements:
- Python 3.8+
- Scientific computing libraries (NumPy, SciPy, pandas)
- Quantum mechanics libraries (qutip)
- Cosmological analysis tools (healpy)
- Machine learning frameworks (scikit-learn, SHAP)

## Key Features

- **Monte Carlo Universe Simulations**: Generate ensembles of universes with varying initial (E,I) conditions
- **Law Lock-In Dynamics**: Model the transition from fluctuating to stable physical laws
- **Cosmological Observables**: Generate CMB-like sky maps and analyze large-scale structure
- **Anomaly Detection**: Scan for statistical features like the CMB Cold Spot and multipole alignments
- **Explainable AI Integration**: Use XAI methods to probe relationships between initial conditions and outcomes

## Scientific Context

TQE addresses fundamental questions in cosmology:
- Why do stable, complexity-permitting physical laws exist?
- How might physical constants be dynamically selected rather than fixed?
- What mechanisms could explain fine-tuning without invoking anthropic reasoning alone?

The framework provides a quantitative, testable approach to these questions through computational simulation.
